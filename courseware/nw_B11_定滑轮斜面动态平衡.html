题干信号：绳/定滑轮连接物块与竖直悬挂物

契合分析：系统由定滑轮滑绳连接、N 被水平力缓慢拉偏，悬绳张力 T 随偏角增大而增大（M 绳拉力必增 → B 对）；M 受静摩擦先减后增取决于 T 与 Mg·sinα 比较，命中“斜面+悬挂组合”（phy0392）与“双绳旋转动态平衡”（phy0202）。契合度高。

分步讲解

①N 结点三力平衡 → T 随 β 增大
对 N：受 T（沿绳）、mNg（竖直向下）、水平拉力 F 三力平衡。竖直分 T·cosβ = mNg ⇒ T = mNg/cosβ，β↑ → cosβ↓ → T 单调增大（选项 B 对）；水平分 F = mNg·tanβ 也增大（故 A 的“可能保持不变”错）。
②M 沿斜面的摩擦方向判定
绳张力 T 沿斜面向上拉 M，M 重力沿斜分量 Mg·sinα 沿斜向下。比较：若 T > Mg·sinα，M 有上滑趋势，静摩擦沿斜向下，大小 f = T − Mg·sinα；若 T < Mg·sinα，静摩擦沿斜向上，f = Mg·sinα − T。
③静摩擦为何“先减后增”
T 随 β 单调增大。若初始 T₀ < Mg·sinα（摩擦沿斜向上），则随 β 增大 f 沿斜向上逐渐减小到 0，越过反号点后再增大（方向改为沿斜向下）。故“M 的摩擦力大小可能先减小后增加”（选项 D 对）；只有当全程保持同向时才一直增（所以 C 的“一定一直增加”错）。
④组合出答案
T 一定一直增加（B 对）；M 的摩擦可能先减后增（D 对）⇒ 正确选项 B、D。
要点：定滑轮 → 绳张力处处相等；N 结点三力平衡用拉密/力三角形看 T 单调；M 摩擦方向随 T 与 Mg·sinα 的相对大小反号。“可能”二字提示存在反号区间即可，不必保证全程都有。

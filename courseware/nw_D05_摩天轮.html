原题（摩天轮 · 单选）

某同学乘摩天轮随座舱在竖直平面内做匀速圆周运动，依次从 A(顶) 到 B(侧) 到 C(底)。下列说法正确的是？
A
该同学机械能守恒
✗ 错误——匀速圆周速度大小不变 → 动能不变，但高度变化 → 重力势能变，机械能 = 动能+势能不守恒（竖直面匀速圆周不守恒，水平面才守恒）。
B
座舱对该同学的作用力大小一直不变
✗ 错误——作用力须提供向心力，随位置变：最低点最大 N=mg+mω²r，最高点最小 N=mg−mω²r，并非一直不变。
C
重力对该同学做功的瞬时功率在 B 点最大
◆ 正确答案：C
瞬时功率 P=mg·v_y，竖直分速 v_y 在侧点 B（水平位置）最大、在顶/底最小 ⇒ P 在 B 点最大。
D
仅增大匀速圆周转速，该同学在 A 点受座舱作用力一定增大
✗ 错误——A 点（顶）N = mg − mω²r：增大转速 ω 使 mω²r 增大，N 反而减小（并非增大）。

记忆卡对碰 · 契合分析

摩天轮是「竖直面匀速圆周」典型模型：关键在于区分「匀速（速度大小恒定 → 向心力/动能恒定）」与「高度变化（→ 势能/机械能变化）」，并逐点用向心力列式。
◆ 命中卡 1 · phy0897（中契合）　机械能守恒·圆周运动：匀速圆周是否守恒看运动平面——水平面守恒，竖直面不守恒。
◆ 命中卡 2 · phy0681（中契合）　竖直圆周·双轨弹力随速度变化：最高点弹力随 v 与临界 √(gr) 的比对而变（类比 N 随 ω²r 变化）。
◆ 命中卡 3 · phy0677（中契合）　竖直圆周·外轨（绳）模型：弹力只能指向圆心，最高点不能提供支撑（与摩天轮座舱可支撑不同）。
◆ 命中卡 4 · phy0797（中契合）　机械能·功率公式：瞬时功率 P=Fv（含夹角 P=Fvcosθ），此处 P=mg·v_y。
契合结论：匀速圆周速度大小不变 → 动能不变但势能变 → 机械能不守恒，命中『匀速圆周问机械能是否守恒』（phy0897）；支持力在最高/最低点用向心力列式命中竖直圆周弹力卡（phy0681）。核心缺口在“竖直面匀速圆周与绳/杆变速圆周的区别”信号。
★ 新增记忆卡 · 圆周运动·竖直面匀速圆周(摩天轮)与变速竖直圆周的区别
信号：摩天轮/转轮竖直面内匀速圆周运动，问机械能、支持力或某点功率。
结论：匀速圆周速度大小恒定 → 动能不变、向心力大小恒定 F合=mω²r 不变，但重力势能随高度变 → 机械能不守恒；支持力随位置变：最低点 N=mg+mω²r 最大、最高点 N=mg−mω²r、侧点斜向提供向心力；重力做功功率 P=mg·v_y 在最高/最低点（v_y=0）为 0、在水平侧点最大。
警惕：把匀速圆周当绳模型变速圆周、或在机械能守恒判断上想当然。

分步讲解

①判断机械能（选项 A）
匀速圆周：速度大小恒定 → 动能 Ek 不变；但高度连续变化 → 重力势能 Ep 改变。故机械能 E = Ek + Ep 不守恒（A 错）。值得注意的是：向上/向下过程速度大小都不变（非变速），向心力大小 mω²r 恒定。
②支持力随位置变化（选项 B）
座舱须提供向心力，用最低点 / 最高点向心力列式：最低点(底C)：N − mg = mω²r ⇒ N_C = mg + mω²r（最大） 最高点(顶A)：mg − N = mω²r ⇒ N_A = mg − mω²r（最小）故作用力大小随位置而变，非一直不变（B 错）。
③重力即时功率（选项 C）
瞬时功率 P = mg·v_y（v_y 为竖直分速）。匀速圆周中 v_y = ωR·cos(φ)，在侧点 B（水平位置）v_y 最大、在顶/底 v_y=0。故 P 在 B 点最大（C 对）。
④增大转速对 A 点（选项 D）
A 点 N = mg − mω²r。增大转速 ω → mω²r 增大 → N 减小（而非增大），D 错。
⑤汇总
机械能不守恒、支持力随位置变、重力功率在 B 最大、增转速使 A 点 N 减小 ⇒ 仅 C 正确。回到上方沙盘拖动位置角：动能线恒平、势能/机械能随高度起伏、N 在底最大顶最小、P 在 B(90°) 最高。
防错：① 竖直面匀速圆周 ≠ 变速竖直圆周（后者最高点有临界 √(gr)）；② “匀速”自动背出动能守恒，但机械能守恒还要看高度；③ 重力功率看竖直分速 v_y 而非总速度。

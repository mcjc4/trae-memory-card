为研究高铁某段直线运动，同学绘制 x/t² – 1/t 图像（未告知加速或减速），直线过点 (0.1, 0) 与纵轴截距 -4。下列说法正确的是？
A
该车处于加速状态
✗ 错误——由纵截距 a/2 = -4 得 a = -8 m/s²，初速 v₀=40>0，二者同号异号？v₀ 与 a 反号 → 实际为减速（a 与 v₀ 反向）（v₀>0、a<0 即减速），并非「加速」。
B
该车的初速度为 40 m/s
◆ 正确答案：B
直线过 (0.1,0)、纵截距 -4，斜率 = v₀ = [0−(−4)]/0.1 = 40 m/s，即初速度 v₀ = 40 m/s。
C
该车的加速度大小为 4 m/s²
✗ 错误——纵截距 = a/2 = -4，故 a = -8 m/s²，大小为 8 m/s²（4 是截距值，不是 a）。
D
该车在前 2 秒的位移为 96 m
✗ 错误——前 2 s 位移：x = v₀t+½at² = 40×2 + ½×(-8)×4 = 80 − 16 = 64 m（不是 96 m）。

记忆卡对碰 · 契合分析

题干只给一条直线（过定点、定截距）而不细说每个物理量，正是「非常规图像 → 自推导线性式 → 读斜率与截距」的考查套路：把 x=v₀t+½at² 两边同除以 t²。
◆ 命中卡 1 · phy0247（强契合）　出处：物一轮039.利用函数知识分析陌生图像_笔记　已知函数类型分析图像：由运动学公式自主推导纵坐标关于横坐标的表达式，再对照 kX+b 读斜率截距；警惕死记结论（不同坐标组合意义不同）。
◆ 命中卡 2 · phy0256（强契合）　出处：物一轮040.确定斜率与线下面积意义的通用方法_笔记　非常规图像求参综合：通法是先变形出一次函数再按斜率/截距求参；x/t-t 截距是 v₀、斜率是 ½a，v²-x 斜率是 2a——系数必须推导出来。
◆ 命中卡 3 · phy0263（中契合）　出处：物一轮042.记忆并使用四个基本公式_笔记　匀变速四个基本公式中选含已知量与待求量的公式（此处即 x=v₀t+½at²）。
契合结论：把 x=v₀t+½at² 除以 t² 得 x/t²=v₀(1/t)+a/2，即直线 Y=v₀X+a/2，命中『已知函数类型 / 非常规图像求参』（phy0247/0256）强峰。核心缺口是该特定“两边同除以 t² 建立线性”的纵除变换操作信号。
★ 新增记忆卡 · 运动学图像·x/t² 对 1/t 的纵除变换建模
信号：给出 x/t²–1/t（或 x/t–t、v²–x 等）非常规图像且为直线，求初速度/加速度。
结论：把 x=v₀t+½at² 两边同除相应量化为线性：x/t² = v₀(1/t)+a/2 ⇒ 纵=x/t²、横=1/t 时斜率=初速度 v₀、纵截距=a/2。
警惕：记反次序——「x/t² 对 1/t」斜率为 v₀，别与「v²-x」（斜率=2a）混淆。

分步讲解

①列出基本公式
匀变速直线运动位移公式：x = v₀t + ½at²
②两边同除以 t² 化线性
欲让纵轴为 x/t²、横轴为 1/t，于是：x/t² = v₀·(1/t) + a/2对照直线 y=kX+b ⇒ 斜率 k = v₀，纵截距 b = a/2。这正是题干给的 x/t²–1/t 直线。
③由截距求加速度
纵截距 = -4，故 a/2 = -4 ⇒ a = -8 m/s²（选项 C 的“加速度大小 4”是拿截距当加速度，错；大小应为 8）。
④由斜率求初速度
斜率 = [0−(−4)]/(0.1−0) = 4/0.1 = 40 m/s = v₀（命中点 (0.1,0)）。选项 B 正确。
⑤判定运动性质与前 2 s 位移
v₀=40>0 而 a=-8<0，两者反向 ⇒ 减速（非加速），A 错；前 2 s 位移 x=v₀t+½at² = 40×2+½×(−8)×4 = 64 m（非 96 m），D 错。故本题选 B。
一句话：把 x=v₀t+½at² 两边同除以 t²，让坐标直接给出斜率和截距——斜率=v₀、纵截距=a/2。拖动上方滑块看直线：v₀ 控制斜率（旋转），a 决定截距（上下平移）。

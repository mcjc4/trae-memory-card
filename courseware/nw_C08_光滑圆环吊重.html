甲、乙站在水平地面上，光滑圆环套在一条不可伸长的轻绳上，圆环下端吊一重物。两人缓慢放绳，重物竖直向下移动一小段距离。
设光滑环为“活结”：两段绳张力处处相等；重物下行 → 两段绳相对竖直变陡（绳角 θ 减小）。

判定
A 正确
互动重点：光滑环套绳 → 两段绳张力相等 T；重物竖直下移(放绳) → θ 减小。
(1) 竖直：2T·cosθ = mg ⇒ T = mg/(2cosθ)；每侧竖直分量 Ty = T·cosθ = mg/2 恒定 → 地面支持力 N 分不变。
(2) 水平：静摩擦源于绳水平分量 Tx = T·sinθ = (mg/2)·tanθ，放绳使 θ 减小 → Tx(摩擦)减小（不“保持不变”、也不“变大”）。

选项判定

A
地面对甲的支持力保持不变
◆ 正确：A 对。 每侧绳竖直分量 Ty = mg/2 恒为常数，与 θ 无关；地面支持力 N 甲 = G甲 + Ty 恒定。
B
地面对甲的支持力逐渐变大
◆B 错。 绳竖直分量恒定 → 支持力不变（并非变大）。
C
地面对乙的摩擦力保持不变
◆C 错。 摩擦 f = (mg/2)·tanθ，放绳使 θ 减小 → f 减小（在变化），并非“保持不变”。
D
地面对乙的摩擦力逐渐变大
◆D 错。 放绳使 θ 减小 → tanθ 减小 → 静摩擦 减小，而非“变大”。

故正确为 A：支持力恒不变；绳角减小使摩擦单调减小。

分步讲解

①锁死活结本质
光滑圆环套绳，绳可在环内自由滑动 → 属活结：绳中张力处处相等 T，且重物使两段绳关于竖直对称。
②环结点三力平衡
结点受两段绳张力（各 T，与竖直夹角 θ）+ 重物重力 mg，三力平衡：竖直方向 2T·cosθ = mg ⇒ T = mg/(2cosθ)。
③地面垂直方向（支持力）
每侧绳对各自的人仅提供竖直分量 Ty = T·cosθ = mg/2（恒为常数）。地面对甲支持力 N甲 = G甲 + Ty，恒定不变 ⇒ A 对；B 错。
④地面水平方向（静摩擦）
绳的水平分量沿水平指向内，需地面静摩擦来平衡：f = Tx = T·sinθ = (mg/2)·tanθ。放绳→重物下移→两段绳更竖直→θ 减小→tanθ 减小→摩擦减小 ⇒ 非“保持不变(错)”、非“变大(错)”，C、D 均错。
⑤答案
综上，只有 A 正确。回到沙盘调小 θ（更放绳）可见 N 平线不变、f 曲线下降。
易错：①把光滑环当死结（两段张力不等）；②把奇数竖直分力当变化、误判支持力/摩擦方向；③混淆绳角随放绳是变“陡”还是变“平”——放绳使绳变陡（θ 减）即摩擦变小。

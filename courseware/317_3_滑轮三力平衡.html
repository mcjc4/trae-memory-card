题3 · 滑轮三力平衡

2026 湖北十一校联考 · 课后达标检测　—— 三力平衡验证 · 力的三角形

原题

竖直木板铺上白纸，在板上固定两个光滑的滑轮 A、B，绕过滑轮的细绳在结点 O 处打结，绳的自由端各挂若干钩码（每个钩码质量均相等）。系统平衡时，按钩码个数读出连接 O 的三段绳（OA、OB、OC）的拉力 F₁、F₂、F₃。
(1) 改变钩码个数（每组三个数分别表示 F₁、F₂、F₃ 的个数），使结点可能平衡的是（　） A. N₁=N₂=2，N₃=5　B. N₁=1，N₂=4，N₃=6　C. N₁=N₂=N₃=4　D. N₁=3，N₂=4，N₃=5
(2) 拆下钩码（取下重物）前，最重要的操作是（　）A. 标记 O 位置并记录 OA/OB/OC 三段绳方向　B. 用刻度尺量三段绳长度　C. 用量角器量三绳夹角　D. 用天平测钩码质量
(3) 在白纸上用作图法检验三力平衡，作图正确的是（　）〔甲：F₁、F₂ 的合力 F合 与 F₃ 等大反向；乙：F合 与 F₃ 不在同一直线上〕

说明：钩码个数即力的大小（单位：G）。拖动端点可同时改方向与大小；滑杆只改大小、保持当前方向。本实验结论依托“三力平衡→任意两边之和大于第三边”。

选项判定（点击选项查看正误）

(1) 改变钩码个数，能实现平衡的是

AN₁=N₂=2，N₃=5作答
✗ 错误。 2+2=4 < 5，两边之和小于第三边，无法构成力的三角形，不能平衡。
BN₁=1，N₂=4，N₃=6作答
✗ 错误。 1+4=5 < 6，两边之和小于第三边，不能平衡。
CN₁=N₂=N₃=4作答
✔ 正确。 任意两边之和 4+4=8 > 第三边 4，且任意两边之差小于第三边，三力可闭合，能平衡。
DN₁=3，N₂=4，N₃=5作答
✔ 正确。 3+4>5、4+5>3、5+3>4 均成立（恰为常见的 3–4–5 三角），能平衡。答案 CD。

(2) 拆下钩码（取重物）前，最重要的操作是

A标记结点 O 位置，并记录 OA、OB、OC 三段绳的方向作答
✔ 正确。 O 位置与三段绳方向确定后才可在纸上精确作图（作出力的平行四边形/三角形）。
B用刻度尺量出三段绳的长度作答
✗ 错误。 拉力大小由钩码个数决定，绳长与力无关，量长度无意义。
C用量角器量出三段绳的夹角作答
✗ 错误。 夹角可由“记录的方向”在纸上直接作图得到，无需量角器。
D用天平测出每个钩码的质量作答
✗ 错误。 钩码质量已知且彼此相等，直接数个数即可，不必用天平。答案 A。

(3) 用作图法检验三力平衡，作图正确的是

甲F₁、F₂ 的合力 F合 与 F₃ 等大反向作答
✔ 正确。 F₁、F₂ 的合力 F合 与 F₃ 在一条直线上且等大反向（虚线合力和虚线共线），三者合力为零。答案 甲。
乙F合 与 F₃ 不在同一直线上作答
✗ 错误。 力是矢量，三力平衡时 F₁ 与 F₂ 的合力必须与 F₃ 大小相等、方向相反（同一直线）。乙图 F合 与 F₃ 不共线，合力不为零，错误。

分步讲解

1原理：三力共点平衡
结点 O 受三段绳拉力 F₁、F₂、F₃ 而平衡，故 F₁+F₂+F₃=0，即任意两力的合力与第三力等大反向；三力必可构成一个闭合的力的三角形。
2判定能否平衡的充要条件
三力（大小 m₁,m₂,m₃）能构成闭合的力的三角形的充分必要条件为：
m₁+m₂ > m₃ m₂+m₃ > m₁ m₃+m₁ > m₂ （任意两边之和大于第三边，且每边小于另两边之和）
3(1) 枚举各选项
A (2,2,5)：2+2=4<5 ✗　B (1,4,6)：1+4=5<6 ✗
C (4,4,4)：4+4>4 ✓　D (3,4,5)：3+4>5 ✓
故可完成的是 C、D。可到上方沙盘点击“例析”按钮直观验证。
4(2) 记录结点与绳方向
拆下钩码后拉力消失，若要事后作图，必须先标记结点 O 的位置，并把OA、OB、OC 三段绳在白纸上的方向记下来（沿绳画出直线）。量绳长、量夹角、用天平都不必：拉力由钩码个数表征，方向由图直接可得。答案 A。
5(3) 作图：平行四边形定则
以 F₁、F₂ 为邻边作平行四边形（或直接用力的三角形），其对角线即合力 F合。三力平衡要求 F合 与 F₃ 等大反向（在同一直线上）。甲图正确，乙图 F合 方向画错，未与 F₃ 共线反向，错误。答案 甲。

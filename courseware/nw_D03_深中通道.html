原题（深中通道 · 单选）

深中通道大桥：内、外侧主索与桥梁平面夹角 30°。桥梁重 1.6×10⁸ N 仅由 200 条竖直吊索承担，吊索固定于主索上，主索由东西两锚碇稳定。每条主索承担竖直吊索的拉力为？
A
1.6×10⁸ N
◆ 正确答案：A · 1.6×10⁸ N
每侧主索需平衡总重的竖直分量 G/2 = 0.8×10⁸ N，主索拉力 T 满足 T·sin30° = G/2 ⇒ T = (G/2)/sin30° = 1.6×10⁸ N。
B
0.8×10⁸ N
✗ 错误——0.8×10⁸ N 是每侧主索承担的竖直分量 G/2，并非主索拉力本身；主索拉力需把竖直分量沿 30° 方向反推（再除以 sin30°）。
C
0.8×10⁷ N
✗ 错误——这是 每条吊索的竖直分力（G/200 = 8×10⁵ N ≈ 0.08×10⁷ N）数量级混淆，并非主索拉力。
D
0.8√3×10⁷ N
✗ 错误——若用水平分力与夹角反推会得 G/(2·cosθ) = (G/2)/cos30° = 0.8×10⁸/0.866 ≈ 0.92×10⁸ N，与√3 混淆；正确是除以 sin30°。

信号：悬索桥、吊索、主索间距题：给定总重由 N 条竖直吊索承担，或主索与桥面夹角，求每条吊索拉力。
结论：先由总数把总重分摊为每条竖直分量 F竖=G/N；再沿主索方向分解：F索=F竖/sin(夹角)（把竖直分量当作 F索 的竖直分量反推）。全程注意单位（总重分给 N 条）与角（与桥面夹角）。
警惕：忘记先除以条数、直接把总重当单条算。

分步讲解

①厘清受力对象
总重 G = 1.6×10⁸ N 由 200 条竖直吊索承担，每条吊索竖直向上拉桥面。竖直方向每一条吊索分得：F竖_每条 = G/N = 1.6×10⁸/200 = 8×10⁵ N（这是每条吊索的竖直拉力）。
②并入主索：每条竖直分量
吊索固定于主索上，主索把各条吊索的竖直拉力汇集。由于左右对称、东西两锚碇均衡，每侧主索承担总重一半的竖直分量：V = G/2 = 8×10⁷ N
③沿主索 30° 反推拉力
主索与桥面夹角 θ=30°。主索拉力 T 的竖直分量 = T·sinθ 恰等于该侧承担的竖直分量 V：T·sin30° = G/2 ⇒ T = (G/2)/sin30° = (8×10⁷)/0.5 = 1.6×10⁸ N
④对照选项
T = 1.6×10⁸ N，即 选项 A。辨析：0.8×10⁸ N（B）只是每侧竖直分量 G/2；8×10⁵ N（≈0.08×10⁷）是每条吊索分力而非主索拉力，两者数量级都不同。
⑤防错要点
① 先除以条数 N，勿把总重 1.6×10⁸ 直接当单条；② 反推用的是竖直分量除以 sinθ（下拉）而不是 cosθ；③ 分清「每条吊索 8×10⁵ N」与「每条主索 8×10⁷ N」两个层级。
一句话：「先分摊 G/N → 每侧得 G/2 → 再沿主索 30° 反推 T=(G/2)/sinθ」。拖动上方滑块验证：条数越多每条越省力，夹角越小主索拉力越大。

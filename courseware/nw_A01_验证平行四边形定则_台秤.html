分步讲解 · 验证平行四边形定则

①力的图示而非示意图
作图表示力必须用力的图示（含比例标度，箭头长度可按比例量取力的大小），而不能用仅表示方向、不标大小的示意图——因为本题需要量取边长读出 F₂ 数值。
②“台秤示数为 0”即接触力为零
台秤示数为 0 → 物块所受支撑力 N=0 → 物块的重力 G 完全由两根绳的拉力 F₁、F₂ 的合力 R 平衡，即 R = F₁ + F₂ = −G。回到沙盘拖动分力，验证示数为 0 时对角线恰好与绿箭头 G 等大反向。
③完成平行四边形求 F₂
按比例作平行四边形：两邻边对应 F₁（弹簧秤读数 4.0N）与待求的 F₂，对角线即合力 R=G。实测 F₂ 由对角线与邻边的几何关系 / 刻度读出（用三角形定则求一边，如 F₂ = √(G²+F₁²−2GF₁cos∠OAG) 或按图量取）。
④OB 转竖直的动态变化
保持 OA 方向不变、示数恒为 0（即合力 R 恒定），OB 逆时针缓转到竖直：用拉密定理 / 辅助圆 / 力三角形判定——典型结果为 F₂ 先减后增、F₁ 单调变化（取决于转动起点在极值两侧的位置）。
要点：把“示数为 0”等价为“该接触力为零、其余力完全平衡”；作图用力的图示并保留标度；转动类动态平衡用拉力三角形或拉密定理判定单调性。

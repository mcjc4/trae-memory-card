信号：平抛运动中问动能 Ek 或重力势能 Ep 随水平位移 x 的图像形状 → 结论：平抛 t=x/v₀，代入 v²=v₀²+(gt)² 与 h=½gt² ⇒ Ek = ½mv₀²+(mg²/2v₀²)x²（随 x 下凹递增、非直线），Ep = Ep₀−(mg²/2v₀²)x²（上凸递减）；而随竖直下落高度则 Ek∝h 线性。警惕：误以为 Ek、Ep 随 x 线性而误选“直线”选项。

分步讲解

①用时与位移关系
平抛水平匀速：t = x / v₀；竖直自由落体：垂直分速 vy = g·t = gx/v₀，下落高度 h = ½gt² = gx²/(2v₀²)。
②动能对 x 的函数
Ek = ½m(v₀² + vy²) = ½mv₀² + ½m(gt)²，代入 t=x/v₀：Ek = ½mv₀² + (mg²/2v₀²)·x²。含 x² 正系数 → 有截距、下凹递增二次曲线 ⇒ B 对。
③重力势能对 x 的函数
Ep = Ep₀ − mgh = Ep₀ − mg·(gx²/2v₀²) = Ep₀ − (mg²/2v₀²)·x²。x² 负系数 → 有正截距、上凸递减二次曲线 ⇒ D 对。
④排除直线
Ek–x 不过原点（有初始动能）、Ep–x 递减但呈曲线，均非直线 ⇒ A、C 错。
⑤答案
正确 B、D。回到沙盘拖 t：两点沿二次曲线移动，机械能总和 E=Ek+Ep 保持恒定（守恒）。
易错：把「随水平位移 x」误当「随竖直高度 h」——随 h 才线性，随 x 是平方曲线。这是本题的丢分点。

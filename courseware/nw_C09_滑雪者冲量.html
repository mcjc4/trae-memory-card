互动重点：冲量 I = F·t，方向恒与力同向，与运动方向无关。
(1) 重力冲量 = mgt竖直向下（选项 A 说“沿斜面向下”​错）；
(2) N = mg·cosα，冲量 N·t ≠ 0（B 错）；
(3) 阻力冲量 = f·t（≠ mg·t·sinα，C 错）；
(4) 合力 = mg·sinα − f，冲量 = (mg·sinα − f)·t 沿斜面向下（D 对）。

选项判定

A
重力 mg 的冲量沿斜面向下
◆A 错。 重力方向竖直向下，冲量方向与该力同向 → 重力冲量竖直向下（=mgt），而非沿斜面。
B
支持力 FN 的冲量等于零
◆B 错。 FN = mg·cosα ≠ 0，冲量 = FN·t ≠ 0（方向垂斜面），并非零。
C
阻力 f 的冲量等于 mg·t·sinα，方向沿斜面向上
◆C 错。 阻力 f 的冲量 = f·t（≠ mg·t·sinα），方向沿斜面向上。数量改错了。
D
合力的冲量等于 (mg·sinα − f)·t，方向沿斜面向下
◆ 正确：D 对。 垂直斜面方向 N 与 mg·cosα 平衡；沿斜面合力 = mg·sinα − f（向下），故 合冲量 = (mg·sinα − f)·t，方向沿斜面向下。正确：D。

分步讲解

①受力分析 + 正交分解
滑雪者受：重力 mg（竖直向下）、支持力 N（垂斜面）、沿斜面向上阻力 f。把重力沿斜面与垂斜面分解：mg·sinα（沿斜面，使下滑）+ mg·cosα（垂斜面）。
②垂直斜面方向平衡
垂直斜面：N = mg·cosα，二力平衡，而无位移做功层面也成立；故支持力冲量 FN·t = mg·cosα·t ≠ 0 → B 错。
③各力冲量（方向恒等于力的方向）
重力冲量 mg·t 竖直向下（非沿斜面，A 错）；阻力冲量 f·t 沿斜面向上（≠ mg·t·sinα，C 错）。
④合力冲量
沿斜面合力 = mg·sinα − f（向下，＞0 则加速），合力冲量 (mg·sinα − f)·t 沿斜面向下 → D 对。
⑤动量定理复核
由匀加速：末速 v=√(2as)，也可对上式动量定理 I=(mg sinα−f)t = mv 自洽验证。正确 D。
易错：冲量方向必须与力同向，与速度/位移方向无关——重力冲量永远竖直向下，不随斜面方向改变。

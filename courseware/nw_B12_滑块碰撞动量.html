设计电动窗帘简化模型：多个质量均为 1kg 的滑块在光滑水平滑轨上滑动，忽略阻力。电机对滑块 1 施加水平向右恒力，推动滑块 1 以 0.40 m/s 与静止滑块 2 碰撞，碰撞时间 0.04 s，碰后两滑块共同速度 0.22 m/s。
A
该过程动量守恒
✓ 判断：对（碰撞瞬间内力远大于外力）
B
滑块 1 受到合外力的冲量大小为 0.18 N·s
✓ 判断：对（|Δp₁| = m|v−v₁|）
C
滑块 2 受到合外力的冲量大小为 0.40 N·s
✗ 判断：错（|Δp₂| = m·v = 0.22 N·s，非 0.40）
D
滑块 2 受到滑块 1 的平均作用力大小为 5.5 N
✓ 判断：对（F̄ = |Δp₂|/Δt = 0.22/0.04 = 5.5 N）
“选不正确的” → 答案 C。A、B、D 正确，仅 C 把滑块 2 冲量误写成 0.40 N·s。

分步讲解 · 逐选项验算

①A · 动量守恒
碰撞时间仅 0.04 s，碰撞内力（接触力）远大于电机等外力 → 碰撞瞬间动量守恒。理想化下内部冲量占主导，“该过程动量守恒”成立（A 对）。
②B · 滑块1的冲量
取滑块1为对象，合力冲量 = 动量变化量：Δp₁ = m·(v−v₁) = 1×(0.22−0.40) = −0.18 N·s，大小 0.18 N·s（B 对）。
③C · 滑块2的冲量（易错陷阱）
滑块2由静止到共速：Δp₂ = m·v = 1×0.22 = 0.22 N·s，并非 0.40。0.40 是滑块1的初速度数值，勿把初速度当冲量（C 错）。
④D · 平均作用力
滑块2受滑块1的平均作用力 = 滑块2的合力（仅接触力）＝ Δp₂/Δt = 0.22 / 0.04 = 5.5 N（D 对）。综合：A、B、D 正确，选“不正确”的 → C。
要点：合冲量 = Δp = 合力 × 接触时间；完全非弹性碰撞用单方程动量守恒解 v共；平均作用力 = Δp/Δt。别把“初速度数值”误当“冲量”。
